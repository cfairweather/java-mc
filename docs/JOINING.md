# How to join

You need a paid Minecraft: Java Edition account signed in with Microsoft. The
server only accepts accounts on its whitelist, so send your exact username to
the host first.

## Full pack (default)

1. Install the [Modrinth App](https://modrinth.com/app) (or Prism Launcher).
2. Download the latest `friends-server-full-<version>.mrpack` from the
   [releases page](https://github.com/cfairweather/java-mc/releases).
3. In the Modrinth App: **Library → Create → From file**, pick the `.mrpack`.
   It installs Minecraft 26.2, Fabric, and every mod. Prism: **Add Instance → Import**.
4. Sign in with your Microsoft account inside the launcher.
5. Play. The server is already in your multiplayer list.

When the host publishes a new pack version, repeat steps 2 and 3 (the launcher
offers to update the existing profile).

## Vanilla-only (if the server is running the `core` profile)

Install nothing. Open the vanilla launcher, choose version 26.2, add the server
address under **Multiplayer → Add Server**. The `core` pack is optional and
just adds Sodium and friends for better frame rates.

## Optional

- **Shaders**: Iris is included. Drop a shader pack into the instance's
  `shaderpacks` folder and pick it under Options → Video Settings → Shader Packs.
- **Map**: the host can share a BlueMap link (browser map of the world).
